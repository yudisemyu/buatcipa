# 1. Project Overview

## Project Name

Our Little Universe

(Working title, can be changed later.)

---

## Vision

This website is not a birthday greeting.

It is an interactive digital scrapbook where every interaction represents a memory shared between two people.

The experience should feel warm, cozy, nostalgic, and intimate.

Visitors should finish the experience feeling emotional rather than impressed by technology.

---

## Goal

Create an unforgettable birthday experience that feels handmade.

The website should encourage the visitor to slowly explore every section instead of rushing to the end.

The emotional journey is the product.

---

# 2. Core Experience

The website is experienced as a linear story.

There are no menus.

No navigation bar.

No dashboard.

No unnecessary buttons.

The user only focuses on one scene at a time.

# 6. Website Structure

There are exactly eleven scenes.

No more.

No less.

---

SCENE 1

Loading

Purpose

Prepare the visitor.

Display

Soft animated loading.

Small decorative stars.

Simple loading text.

Music does NOT autoplay.

---

SCENE 2

Invitation

The visitor receives a digital birthday letter.

There is only one button.

Open Letter

After pressing,

music starts.

Transition to Scene 3.

---

SCENE 3

Memory Password

The visitor must answer one personal memory.

Examples

"What café did we visit first?"

or

"What nickname do you always call me?"

Wrong answer

Friendly response.

Never punish.

Unlimited attempts.

Correct answer unlocks the journey.

---

SCENE 4

Story Chapters

This section introduces the relationship.

Presented as chapters.

Example

Chapter One

"The First Hello"

Each chapter contains

- title
- one photo
- one paragraph

Target

3–5 chapters.

Each chapter appears while scrolling.

---

SCENE 5

Timeline

A vertical timeline.

Contains important memories.

Each memory card includes

- date
- title
- image
- short story

Cards animate gently into view.

Target

8 memories.

---

SCENE 6

Memory Gallery

Grid of memories.

Contains

Photos

Videos

GIFs (optional)

Clicking opens fullscreen viewer.

No download button.

---

SCENE 7

Mini Game

Only ONE game.

Game type

Memory Matching.

Player flips cards.

Match every pair.

Reward

Cute celebration animation.

Continue button appears.

No score.

No timer.

No losing.

Purpose

Create interaction.

---

SCENE 8

Fake Ending

Everything fades out.

Screen becomes dark.

Display

"The End"

Wait five seconds.

Then

"...or maybe not."

Continue.

---

SCENE 9

Letter

A long birthday letter.

Displayed with typewriter animation.

User can skip animation.

Comfortable reading width.

No distractions.

---

SCENE 10

Voice Message + Gift

Top section

Voice message player.

Bottom section

Gift Box.

Clicking opens

Surprise message

or

QR Code

or

Special coupon

Content is determined later.

---

SCENE 11

Birthday Ending

Final celebration.

Photo collage appears.

Confetti.

Soft sparkles.

Large message

Happy Birthday ❤️

Thank you for being part of my life.

Background music reaches its final chorus.

Fade out.

---

# 7. Audio Experience

Music starts only after user interaction.

Volume

40%

Voice message pauses background music.

Background music resumes afterward.

---

# 8. Motion Principles

Every animation should be

slow

smooth

gentle

Avoid

bounce

shake

spin

rubber effects

Preferred

fade

opacity

blur

small scale

parallax

---

# 9. Interaction Rules

One primary action per screen.

Avoid multiple choices.

Never overwhelm the visitor.

Scrolling is the main interaction.

---

# 10. Accessibility

Support keyboard navigation.

Images require alt text.

Reduced motion mode must disable heavy animations.

---

# 11. Performance Goals

Lighthouse

90+

Images optimized.

Videos lazy loaded.

No unnecessary JavaScript.

---

# 12. Technical Scope

Frontend only.

Static assets.

No authentication.

No backend.

No database.

Deploy on Vercel.
